# 1. Frontend (User Interface)

## **HTML5**

### Why use it:

## Structures the page (header, logo, form fields, buttons)
# Easy to create forms for:

  - First Name
  - Surname
  - Gmail
  - Password
  - Date of Birth
 # Semantic tags improve accessibility

### Justification:

## HTML5 is used because it provides the structural foundation of the RES HUB sign-up page and supports form elements required for collecting user information efficiently.

## CSS3

### Why use it:

* Styles dark blue background
* Creates light gray input boxes
* Centers the layout vertically
* Makes the design responsive

### Justification:

## CSS3 is used to design the visual appearance of the website, ensuring an attractive, consistent, and user-friendly interface aligned with the RES HUB branding.

## JavaScript

### Why use it:

- Form validation
- Password checks
- Email format validation
- Interactive dropdowns
- Prevents empty fields

### Justification:

## JavaScript improves user experience by validating user inputs before submission, reducing errors and ensuring accurate data collection.
